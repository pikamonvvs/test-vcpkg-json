# JSON Example Project

This is an example project demonstrating the use of nlohmann/json library in C++.

## Requirements

- Windows 10/11 x64
- MinGW
- CMake
- vcpkg
- Ninja

## Installation

1. Install CMake
	- Download and install from https://cmake.org/download/
	- Add bin folder to PATH

2. Install Ninja
	- Download from https://ninja-build.org/
	- Add bin folder to PATH

3. Install vcpkg
	- Download from https://github.com/Microsoft/vcpkg
	- Install
	```
	git clone https://github.com/Microsoft/vcpkg.git
	cd vcpkg
	.\bootstrap-vcpkg.bat
	```
	- Add folder to PATH

## Getting started

1. Clone this project

```
git clone https://github.com/pikamonvvs/test-vcpkg-json.git
cd test-vcpkg-json
```

2. Run

```
.\build.bat
```
